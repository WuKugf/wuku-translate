自定义接口

用模板完全掌控请求与响应，可接入 LibreTranslate、自建代理、第三方聚合服务等。

请求定义

支持 a.b[0].c 形式；指向字符串或字符串数组。

可用占位符
  • {{text}}当前单段文本（已做 JSON 转义，不含外层引号）
  • {{texts}}批量文本的 JSON 数组，如 ["a","b"]
  • {{textsPlain}}批量文本按换行拼接的纯文本
  • {{sourceLang}}检测到的源语言，如 en
  • {{targetLang}}目标语言，如 zh-CN
  • {{targetLangName}}目标语言中文名
  • {{model}} / {{apiKey}} / {{temperature}}复用上方 AI 参数
  • {{systemPrompt}}上方系统提示词（已转义）

使用教程

三分钟上手 WUKU 翻译的全部功能。

1. 翻译网页
  • 点击工具栏图标 →「翻译整页」，或按 Alt+Shift+T。
  • 弹窗中可在「纯译文 / 双语对照」之间切换，切换后立即重译当前页。
  • 右键菜单同样提供「翻译当前页面 / 双语对照 / 恢复原文」。
  • 中文页面默认跳过，可在提示条中点「仍然翻译」强制执行。
2. 划词翻译
  • 选中任意文本，旁边会弹出翻译气泡。
  • 气泡内可切换引擎、复制译文、朗读；按 Esc 关闭。
3. 悬浮球
  • 默认显示在页面右侧边缘，半透明胶囊样式。
  • 单击展开菜单：翻译页面、双语对照、显示原文、打开翻译面板、视频字幕开关。
  • 按住拖动可换到左侧或调整上下位置，位置会自动记忆。
4. 翻译面板
  • 从悬浮球菜单或弹窗「打开翻译面板」进入。
  • 左侧输入原文，650ms 后自动出译文；可手动选引擎与目标语言。
  • 支持复制译文与朗读，按 Esc 收起。
5. 视频双语字幕
  • 在弹窗或「增强功能」中开启后，播放支持站点的视频即可看到双语字幕。
  • 内置支持 YouTube、Netflix、B 站、Disney+、Prime Video；其他站点可填自定义选择器。
  • 需要视频本身已开启字幕（CC）。
6. 输入框翻译
  • 在任意输入框（含评论框、搜索框、富文本编辑器）输入中文。
  • 结尾连敲 3 次空格，或按 Alt+Shift+I，内容即刻译为英文（可配置）。
  • 写回方式可选「替换原文」或「追加到原文后」。
7. 漫画 / 图片翻译
  • 需先在「AI 接口」配置支持视觉的模型（如 gpt-4o、qwen-vl-max 等）。
  • 在漫画或截图上右键 → 翻译图片文字。
  • 首次翻译跨站图片时按提示授权图床域名；译文以浮层形式覆盖在图片上，可随页面滚动。
8. AI 接口配置
  • 支持任意 OpenAI 兼容服务：OpenAI、DeepSeek、Moonshot、通义、Ollama、OneAPI 中转等。
  • 填 Base URL 与 API Key → 保存并授权域名 → 测试连接，绿色译文即配置成功。
  • AI 不可用时自动降级到免费线路，不断档。

关于 WUKU 翻译

一个免构建、权限克制的 Chrome 网页翻译扩展。

功能概览
  • 整页翻译：自动识别页面语言，保留 DOM 结构与行内标签。
  • 划词翻译：选中文本弹出气泡，可复制、朗读、切换引擎。
  • 双语对照：原文上/下方插入译文，可随时切回纯译文或原文。
  • 悬浮球 + 翻译面板：页面边缘胶囊入口，抽屉式即输即译面板。
  • 视频双语字幕：主流视频站沉浸式双语字幕。
  • 输入框翻译：三连空格把中文输入即时译为外文。
  • 漫画图片翻译：AI 视觉识别，右键一键翻译图中文字。
  • AI 翻译：OpenAI 兼容接口与自定义请求模板，提示词可编辑。
  • 站点规则：不同网站用不同引擎与显示模式。
快捷键
Alt+Shift+T翻译 / 恢复当前页面
Alt+Shift+S翻译当前选中文本
Alt+Shift+I翻译当前输入框内容

可在 chrome://extensions/shortcuts 中修改。

权限说明
  • storage：保存配置与翻译缓存。
  • contextMenus / activeTab / scripting：右键菜单、快捷键与按需注入页面脚本。
  • translate.googleapis.com / api.mymemory.translated.net：内置免费机器翻译线路。
  • AI 接口域名：不预先申请，保存配置时按域名单独授权（optional_host_permissions）。
隐私

插件不含统计与埋点。开启机器翻译时，待翻译文本会发送到对应免费接口；使用 AI 时发送到你自己配置的服务地址。配置与 Key 只存在于本机浏览器存储。
