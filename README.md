# WUKU 翻译 · 沉浸式网页翻译

一款 Chrome / Edge 浏览器扩展（Manifest V3），提供整页翻译、划词翻译、双语对照、悬浮球与翻译面板、视频双语字幕、输入框翻译与漫画图片翻译，内置机器翻译引擎，并支持自定义 OpenAI 兼容接口与任意请求模板。

- **开发者**：WUKU
- **版本**：1.1.0
- **最低浏览器版本**：Chrome 110

---

## 一、安装

本扩展为**免构建的原生版本**（原生 JS + HTML + CSS），无需 Node.js、npm 或任何打包步骤。

### 方式一：加载已解压的扩展（推荐，便于修改）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择本目录 `wuku-translate`。
4. 固定到工具栏后即可使用。首次安装会自动打开设置页。

### 方式二：从 zip 安装

1. 解压 `wuku-translate.zip` 到任意固定目录（不要放在临时目录，移动后需重新加载）。
2. 按方式一的第 1–3 步加载解压后的目录。

> 更新代码后，在扩展管理页点击该扩展的 **刷新** 按钮即可，无需重装。

## 二、功能与使用

### 1. 整页翻译

- 点击工具栏图标打开弹窗，选择 **纯译文**，再点 **翻译整页**。
- 或使用快捷键 **Alt+Shift+T**（翻译 / 恢复切换）。
- 或在页面右键菜单中选择 **翻译当前页面**。

翻译采用逐文本节点替换：保留原有 DOM 结构、标签、class、事件监听与链接，只替换文本内容，并保留文本节点前后的空白以维持行内排版。已翻译过的页面再次触发时先自动还原，避免重复嵌套。

翻译过程会显示右上角进度胶囊，可随时停止。

### 2. 双语对照

- 弹窗中选择 **双语对照** 后翻译；或右键菜单选择 **双语对照翻译**。
- 原文保持不变，译文以带左侧渐变竖线的块插入到每个段落之后，形成上下对照。
- 可随时在弹窗中切回 **纯译文**，或点 **恢复原文** 完全还原页面。

### 3. 划词翻译

1. 在页面中用鼠标选中任意文本（或键盘 Shift + 方向键选择）。
2. 松手后出现翻译气泡，显示原文与中文译文。
3. 气泡支持：
   - **复制** 译文到剪贴板；
   - **朗读** 译文（浏览器语音合成，优先选择中文语音）；
   - **切换引擎**（下拉选择后立即重译，并记住为该站点的气泡偏好）；
   - **重试**（请求失败时出现）。
4. 点击气泡外部或按 `Esc` 关闭。

若选中的内容已是中文，气泡会直接展示原文并提示无需翻译，不发起网络请求。单次选中超过 2000 字符时不会触发（避免误选整页）。

可在设置页 **通用设置** 中关闭划词翻译，或单独指定划词默认引擎。

### 4. 悬浮球

- 默认显示在页面右侧边缘，半透明胶囊（毛玻璃）样式，始终置顶。
- 单击展开菜单：**翻译页面 / 双语对照 / 显示原文 / 翻译面板 / 视频字幕开关 / 设置**。
- 按住拖动可换到左侧或调整上下位置，位置自动记忆。
- 可在设置页「增强功能」中关闭或调整外观。

### 5. 翻译面板

- 从悬浮球菜单或弹窗「打开翻译面板」进入，页面右侧滑出抽屉。
- 输入原文后约 650ms 自动出译文，可手动选择引擎与目标语言。
- 支持复制译文与朗读，按 `Esc` 收起。

### 6. 视频双语字幕

- 开启后，播放支持站点的视频时实时在字幕下方追加译文，形成沉浸式双语字幕。
- 内置适配 YouTube、Netflix、B 站、Disney+、Prime Video；其它站点可在设置页填写自定义字幕容器选择器。
- 支持「双语对照 / 仅译文」切换；需要视频本身已开启字幕（CC）。

### 7. 输入框翻译

- 在任意输入框（文本框、搜索框、富文本编辑器）输入中文后，**结尾连敲 3 次空格**，或按 **Alt+Shift+I**，即把内容译为外文并写回。
- 写回方式可选「替换原文 / 追加到原文后」，目标语言可配置（默认英文）。

### 8. 漫画 / 图片翻译

- 在图片上**右键 → 翻译图片文字（漫画 / 截图）**，AI 视觉模型识别图中文字后，以浮层形式显示原文与译文对照。
- 需先在「AI 接口」配置支持视觉的模型（如 gpt-4o、qwen-vl-max）；可在「增强功能」中为图片翻译单独指定模型。
- 跨站图片首次使用需对图床域名授权（设置页 → 增强功能 → 图片域名授权）。

### 9. 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt+Shift+T` | 翻译 / 恢复当前页面（切换） |
| `Alt+Shift+S` | 翻译当前选中的文本 |
| `Alt+Shift+I` | 翻译当前输入框中的内容 |

如与其它扩展冲突，可在 `chrome://extensions/shortcuts` 中修改。

### 10. 右键菜单

- 翻译当前页面
- 双语对照翻译
- 翻译选中文本
- 翻译图片文字（漫画 / 截图）
- 恢复原文

### 11. 语言检测与「仅翻译非中文页面」

- 通过 Unicode 区块统计（汉字、假名、谚文、西里尔、阿拉伯、泰文、天城文、拉丁）+ 拉丁语系停用词打分判断语言。
- 页面级检测会采样正文前 6000 字并结合 `<html lang>`。
- 开启「仅翻译非中文页面」后，中文页面会跳过翻译并给出提示，可点「仍然翻译」强制继续。

### 12. 翻译缓存

- 使用 `chrome.storage.local` 持久化，键由「引擎 + 源语言 + 目标语言 + 文本长度 + 文本哈希」组成。
- 相同文本再次出现时直接命中，不重复请求。
- 自动 LRU 裁剪（条目数上限 + 约 3MB 字符上限）。
- 设置页 **缓存与数据** 可查看命中统计、清空缓存、调整上限。

### 13. 失败降级与错误提示

- 主引擎失败时自动按链路降级：`AI / 自定义 → Google → MyMemory`。
- 页面会提示「已降级到 XXX」，弹窗状态卡显示降级原因。
- 常见错误均有中文说明：401/403 鉴权失败、404 接口地址错误、429 限流、5xx 服务端错误、超时、网络不可达、缺少域名权限。
- 缺少接口域名权限时提供「去授权 / 去设置」入口。

## 三、AI 翻译配置

打开设置页（弹窗右上角 **设置**，或扩展详情页的「扩展选项」），进入 **AI 接口** 面板。

| 字段 | 说明 |
| --- | --- |
| Base URL | OpenAI 兼容接口根地址，如 `https://api.openai.com/v1`；扩展会自动拼接 `/chat/completions`（若已包含完整路径则原样使用） |
| API Key | 以 `Authorization: Bearer <key>` 发送 |
| 模型名称 | 如 `gpt-4o-mini`、`deepseek-chat` |
| 温度 | 0–1，网页翻译建议 0.1–0.3 |
| 批量条数 | 单次请求打包的段落数（同时受 2200 字符上限约束） |
| 额外请求头 | JSON 对象，用于自定义鉴权头或组织标识 |
| JSON 数组模式 | 批量时要求模型返回等长同序的 JSON 字符串数组（推荐开启） |
| 系统提示词 | 可编辑，支持 `{{targetLangName}}` 占位符，可一键恢复默认 |

填写后点击 **保存并授权域名**：扩展会针对该接口的 origin 单独申请 host 权限（`chrome.permissions.request`），授权后即可调用。

### 配置示例

| 服务 | Base URL | 模型 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| Ollama（本地） | `http://localhost:11434/v1` | `qwen2.5:7b` |
| OneAPI / 中转 | `https://your-proxy.com/v1` | 按服务商提供 |

> 本地 Ollama 的 `http://localhost:11434` 需要在保存时授权；若浏览器禁止访问本地地址，请确认 Ollama 已设置 `OLLAMA_ORIGINS` 允许来源。

### 自定义请求模板

适合接入 LibreTranslate、自建代理或任意第三方翻译服务。

- **请求地址 / 方法**：支持 `POST`、`GET`、`PUT`，URL 中也可使用占位符。
- **请求头**：JSON 对象，值支持占位符（如 `"X-Token": "{{apiKey}}"`）。
- **请求体模板**：任意文本模板。
- **响应解析路径**：`a.b[0].c` 形式，指向字符串或字符串数组。
- **批量模式**：开启后一次请求多段文本，需在请求体中使用 `{{texts}}`。

可用占位符：

| 占位符 | 含义 |
| --- | --- |
| `{{text}}` | 当前单段文本（已做 JSON 转义，不含外层引号） |
| `{{texts}}` | 批量文本的 JSON 数组，如 `["a","b"]` |
| `{{textsPlain}}` | 批量文本按换行拼接的纯文本 |
| `{{sourceLang}}` | 检测到的源语言，如 `en` |
| `{{targetLang}}` | 目标语言，如 `zh-CN` |
| `{{targetLangName}}` | 目标语言中文名 |
| `{{model}}` / `{{apiKey}}` / `{{temperature}}` | 复用 AI 面板参数 |
| `{{systemPrompt}}` / `{{prompt}}` | AI 系统提示词（已转义） |

**LibreTranslate 示例**

```json
POST https://libretranslate.com/translate
Content-Type: application/json

{
  "q": "{{text}}",
  "source": "{{sourceLang}}",
  "target": "zh",
  "format": "text"
}
```

响应解析路径填 `translatedText`。

### 站点规则

在 **站点规则** 面板中可为特定站点单独指定引擎与渲染模式，优先级高于全局设置；更具体的规则（更长 pattern）优先。

pattern 支持以下写法：

| 写法 | 匹配 |
| --- | --- |
| `example.com` | 该域名及其所有子域名 |
| `*.example.com` | 该域名的子域名 |
| `.example.com` | 该域名及其子域名 |
| `example.com/docs/*` | 该域名下指定路径 |

## 四、目录结构

```

├── background/
│   └── service-worker.js      消息路由、右键菜单、快捷键、脚本注入
├── shared/                    可被 service worker 与 content script 复用的模块
│   ├── core.js                工具函数（克隆、哈希、并发控制等）
│   ├── constants.js           语言表、引擎元信息、默认配置
│   ├── lang-detect.js         语言检测
│   ├── settings.js            配置读写、站点规则匹配与解析
│   ├── cache.js               翻译缓存
│   ├── net.js                 统一请求（超时、重试、错误码、权限）
│   └── engines/
│       ├── index.js           引擎注册、调度、降级链
│       ├── google.js          Google 翻译
│       ├── mymemory.js        MyMemory
│       ├── ai.js              OpenAI 兼容接口
│       └── custom.js          自定义请求模板
├── content/
│   ├── content.js             页面翻译编排（检测、分块、进度、提示）
│   ├── dom.js                 DOM 遍历、纯译文/双语应用与还原
│   ├── ui.js                  Shadow DOM 气泡、进度胶囊、Toast
│   ├── selection.js           划词翻译
│   ├── ball.js                悬浮球（半透明胶囊、拖动换边、菜单）
│   ├── panel.js               翻译面板（右侧抽屉，即输即译）
│   ├── subtitle.js            视频双语字幕（站点适配 + 自定义选择器）
│   ├── input.js               输入框翻译（三连空格 / Alt+Shift+I）
│   └── image.js               漫画图片翻译（AI 视觉 + 浮层对照）
├── popup/                     工具栏弹窗
├── options/                   设置页
├── styles/content.css         双语译文的页面内样式
└── icons/                     16/32/48/128 图标
```

所有网络请求都在 Service Worker 中发出，借助 host 权限避开页面 CORS 限制；页面、弹窗与设置页通过 `chrome.runtime.sendMessage` 委托。

## 五、权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存设置与翻译缓存 |
| `contextMenus` | 右键菜单 |
| `activeTab` | 仅在用户点击扩展时访问当前标签页 |
| `scripting` | 向未注入脚本的页面按需注入 content script |
| `https://translate.googleapis.com/*` | 内置 Google 翻译接口 |
| `https://api.mymemory.translated.net/*` | 内置备用翻译接口 |
| `optional_host_permissions` | AI / 自定义接口域名，仅在保存配置时按 origin 单独申请 |

扩展不申请 `<all_urls>` 的常驻主机权限，也不会读取未主动翻译页面的内容。

## 六、已知限制

1. **内置机器接口为非官方公开接口**：Google `translate_a/single` 与 MyMemory 可能限流、变更或不可用。生产环境建议配置自己的 AI 接口或自定义接口。
2. **动态内容不会自动跟踪**：无限滚动、弹窗、单页路由切换后新出现的内容不会被自动翻译，需要重新触发翻译。
3. **不翻译的内容**：`<iframe>`、Canvas、浏览器内置 PDF 阅读器、Shadow DOM 内部文本、`<pre>/<code>`、输入框占位文本。图片内文字与视频字幕由独立的增强功能模块处理（需 AI 视觉模型 / 站点字幕支持）。
4. **虚拟列表站点**：长列表仅渲染可视区域时，翻译只覆盖当前已渲染的部分。
5. **双语模式的个别布局**：普通块级元素为段后插入；`flex` 容器改为在父级插入兄弟节点，极端布局下可能出现细微间距差异。
6. **划词气泡不覆盖跨 iframe 选择**：扩展仅注入顶层文档（`all_frames: false`）。
7. **朗读依赖系统语音**：使用浏览器 `speechSynthesis`，若无中文语音包则发音可能不准确。
8. **缓存为本地数据**：清理浏览器数据或卸载扩展会丢失缓存与设置。
9. **AI 输出稳定性**：模型可能返回多余解释或数量不符，扩展会做代码块剥离、逐行拆分与长度补齐，但无法保证 100% 对齐，遇到异常可切回机器引擎。
10. **快捷键冲突**：可能被其它扩展占用，需在 `chrome://extensions/shortcuts` 调整。

## 七、隐私

- 待翻译文本会发送到你所选择的翻译服务（Google、MyMemory、你配置的 AI 接口或自定义接口）。
- 扩展本身不收集、不上传统计数据，不包含任何第三方分析脚本。
- 所有设置与缓存仅保存在本机 `chrome.storage.local`。
